⚙️ 번역 API 설정

AI 번역 엔진의 API 키를 등록하면, 사전에 없는 문장을 무료 구글 번역 대신 그 AI가 번역합니다 — 훨씬 자연스럽고 문맥에 맞는 실무 중국어로 번역됩니다. Claude는 console.anthropic.com, OpenAI는 platform.openai.com에서 키를 발급받으세요. 둘 다 claude.ai / ChatGPT 채팅 구독과는 별개로, 사용한 만큼 그 계정에 따로 과금됩니다. 키는 이 브라우저에만 저장되고 index.html 파일 자체에는 들어가지 않습니다. 다만 이 PC를 여러 사람이 쓰거나 개발자도구를 열면 노출될 수 있으니 공용 PC에서는 등록하지 마세요. 아무것도 선택하지 않으면 지금처럼 무료 구글 번역을 계속 사용합니다.

📖 사전 관리

여기서 추가한 용어는 즉시 번역에 반영되고, 이 PC에 저장돼 다음 문서·다음 실행에도 계속 쓰입니다. 엑셀 단어장에 이미 있는 용어를 검색해서 다시 등록하면 그 용어를 "내 수정"으로 덮어씁니다(재정의).
